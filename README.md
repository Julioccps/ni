# NI

> No Internet

This was a little project made without internet access

It's a little VM, Assembler in a single file

## ISA

* NOP
* ADD
* SUB
* LOAD
* STORE
* XOR
* AND
* OR
* NOT
* CMP
* JMP
* JEQ
* MOV
* PRINT
* INPUT

## Registers

All 8 bits

* A
* B
* C
* D
* E

## Idiosyncrasies

The labels aren't real addresses, they are labels to labels
you name a label with its index on the label table
